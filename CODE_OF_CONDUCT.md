# Code of Conduct

Slate is a small open-source project. Be kind.

## Expected

- Assume good intent; disagree respectfully.
- Keep feedback about code and ideas, not people.
- No harassment, hate speech, or deliberate intimidation.
- Do not share others' private data (notes, tokens, emails) without consent.

## Reporting

If something crosses a line, contact the maintainer privately via the GitHub profile for [jaysongiroux](https://github.com/jaysongiroux) or a private security/advisory channel (see [SECURITY.md](SECURITY.md) for vulnerability reports).

Maintainers may warn, edit, or remove contributions that violate this standard.
